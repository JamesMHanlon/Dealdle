# Dealdle

A daily card game. Each day you're dealt seven playing cards. You hold the ones you want, and every other card is redrawn once. Every card is drawn from its own full deck, so duplicates (even identical cards) can happen. Your final hand earns badges worth EP, and its total EP gives it a rarity tier: Trash, Common, Uncommon, Rare, Epic, Anomaly or Mythic.

Features: accounts, lifetime score, day streaks, badge collection, friends (requests, accept and decline), global and friends leaderboards (today, this week, all-time), a one-line poem for your hand, hearts on other players' hands, and a copyable share result. Guests can play too. If a guest signs up the same day, the new account keeps that day's hand.

## Files

| File | What it does |
|---|---|
| `shared/engine.js` | Cards, the 1,077 badge checks (86 hand-written, the rest generated by rules in `generatedBadges`) and scoring. Used by both the server and the browser. |
| `shared/stats.json` | Generated badge odds, EP values and the rarity percentile table. |
| `tools/calibrate.js` | Regenerates `stats.json`. Run `npm run calibrate` after adding or changing badges. |
| `server.js` | The API and static file server. No dependencies. |
| `public/` | The web app. |

## Scoring

A badge's EP is `10 / probability`, where the probability is how often that badge appears in a random seven-card deal. The calibration script measures this over 3 million deals. For badges too rare to measure that way, it uses the exact odds set as `p` in `engine.js`. Badges that share a `family` don't stack: only the highest-scoring badge in each family counts. Rarity tiers come from simulating hands played with a simple hold strategy (`Engine.autoHold`).

All dealing, redrawing and scoring happens on the server (`crypto.randomInt`), so players can't cheat from the browser.

## Running locally

```bash
npm start
```

Then open http://localhost:3000. Data is saved to `data/db.json`.

## Hosting on your website

GitHub Pages can't run the server, so host this on a Node host such as Render, Railway or Fly.io, the same way as rift-draft.

1. Push this folder to its own GitHub repo.
2. On Render, create a **Web Service** from the repo. Set the start command to `npm start` and the environment to `NODE_ENV=production`.
3. Add a **persistent disk** (e.g. mounted at `/var/data`) and set `DATA_DIR=/var/data`. Without one, accounts are wiped on every deploy.
4. Add the custom domain `dealdle.james-mh.com` in Render, then add the CNAME record it gives you in your DNS.
5. Add the game to `Maindashboard/games.js`.

A day runs from midnight to midnight UTC.
